關於 Lumos

2026-08-10

Lumos 是用來保存學習、創作和專案紀錄的個人網站。這裡會慢慢放下程式筆記、作品集、文學練習和一些生活裡值得留下的想法。

網站會放什麼

  • 學習筆記：程式、工具、課程、解題和踩坑紀錄。
  • 文學創作：新詩、古詩、對聯和文字練習。
  • 作品集：GitHub 專案、Demo、設計想法與開發心得。
  • 生活紀錄：閱讀、回顧、短句和日常觀察。

這個網站目前是靜態 GitHub Pages，但已經整理成資料驅動：新增文章後，首頁、分類、標籤和文章列表會一起更新。
